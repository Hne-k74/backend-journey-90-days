# 🚀 90 Days of Backend Development

Hi, I'm Henok, a Software Engineering student at Arba Minch University.
This repo documents my 90-day journey to becoming internship-ready as a backend developer.

## 🎯 Goal

Independently take a requirement like "Build an API for a university clinic" from
database design all the way to a deployed, tested, documented API.

## 🛠️ Stack

JavaScript → Node.js → Express.js → REST APIs → PostgreSQL → Authentication → Testing → Docker → Deployment

## 📅 Roadmap

| Month | Focus |
|-------|-------|
| 1 | JavaScript, Node.js, Express, REST APIs |
| 2 | SQL, PostgreSQL, Authentication (JWT), Clinic API starts |
| 3 | Validation, Testing, Docker, Deployment, Final Project |
